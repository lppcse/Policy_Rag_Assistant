# Policy RAG Assistant

A local, production-grade company-policy question answering assistant built with Python 3.10+, FAISS vector indexing, and a cyclic LangGraph validation workflow. The assistant ingests internal policy documents (leave entitlements, security procedures, HR guidelines), semantically searches them via dense vector retrieval, and generates factual, cited responses strictly constrained to company documentation.

## Configuration Reference

All settings can be configured via environment variables or in a `.env` file at the root of the project:

| Variable | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `OPENAI_API_KEY` | `string` | *(Required)* | OpenAI API secret key (`sk-...`). Raises an error if missing. |
| `EMBEDDING_MODEL`| `string` | `text-embedding-3-small` | Model used for document and query embeddings. |
| `CHAT_MODEL` | `string` | `gpt-4o-mini` | Model used for answer generation, validation, and query rewriting. |
| `TOP_K` | `integer` | `4` | Number of most relevant policy passages retrieved per search. |
| `MAX_RETRIES` | `integer` | `2` | Maximum query rewrite retries before finalizing with audit note. |
| `CHUNK_SIZE` | `integer` | `900` | Target character length per document chunk. |
| `CHUNK_OVERLAP` | `integer` | `150` | Overlap character length between contiguous chunks. |

## Setup & Installation

### 1. Prerequisites
- Python 3.10 or higher
- A valid OpenAI API key with access to `text-embedding-3-small` and `gpt-4o-mini`

### 2. Create and Activate Virtual Environment

```bash
# On Linux / macOS
python3 -m venv venv
source venv/bin/activate

# On Windows (Command Prompt)
python -m venv venv
venv\Scripts\activate.bat

# On Windows (PowerShell)
python -m venv venv
venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Create and Configure OpenAI API Key

The assistant requires an OpenAI API key (separate from a ChatGPT subscription):

1. Go to [https://platform.openai.com](https://platform.openai.com) and sign up or log in.
2. Add prepaid billing credits at [https://platform.openai.com/settings/organization/billing](https://platform.openai.com/settings/organization/billing) (e.g. $5). *Note: Without prepaid credit, requests will fail with a "quota exceeded" error.*
3. Navigate to [https://platform.openai.com/api-keys](https://platform.openai.com/api-keys).
4. Click **Create new secret key**, name it (e.g. `policy-rag`), and copy the key (`sk-...`).
5. Copy `.env.example` to `.env` and paste your key:

```bash
cp .env.example .env
```

Edit `.env`:
```ini
OPENAI_API_KEY=sk-your-actual-api-key-here
EMBEDDING_MODEL=text-embedding-3-small
CHAT_MODEL=gpt-4o-mini
TOP_K=4
MAX_RETRIES=2
```

> **Security Note:** Never commit `.env` or share your API key. `.env` is ignored in `.gitignore`. Running the sample documents costs only a fraction of a cent.

## CLI Usage

You can run commands using either `python -m src.main <cmd>` or `python src/main.py <cmd>`.

### Command 1: Ingest Policy Documents
Reads all `.md` and `.txt` files in `data/policies/`, splits them on markdown headings, computes normalized embeddings, and persists the FAISS index to `index/`:

```bash
python -m src.main ingest
# or: python src/main.py ingest
```

Output:
```
[*] Scanning policy documents in: /path/to/data/policies
[*] Generated 16 contextual chunks across policy files.
[*] Generating embeddings and building FAISS IndexFlatIP index...
[*] Saving vector index to: /path/to/index/faiss.index
[*] Saving chunk metadata to: /path/to/index/metadata.json
[✓] Ingestion completed successfully! 16 chunks indexed.
```

### Command 2: Ask a Single Question
Ask any question against the indexed policies:

```bash
python src/main.py ask "How many days of parental leave are allowed?"
```

#### Suppress Source Passages
Use `--no-sources` to print only the generated answer:

```bash
python src/main.py ask "What is the password length requirement?" --no-sources
```

### Command 3: Interactive Chat Session
Launch an interactive multi-turn policy interrogation terminal:

```bash
python src/main.py chat
```

Inside the session:

## How to Add Your Own Documents

Adding new corporate policies to the assistant requires no code changes:

1. Create a new `.md` or `.txt` file inside `data/policies/` (e.g., `data/policies/remote_equipment.md`).
2. Organize your document with standard Markdown `##` headings for each subsection:
   ```markdown
   # Remote Equipment Policy

   ## Home Office Equipment Allowance
   Full-time remote staff receive a one-time setup stipend of $1,000 for ergonomic desks and chairs.

   ## Monitor and Accessory Provisioning
   Employees may request up to two 27-inch 4K external monitors and an ergonomic keyboard.
   ```
3. Re-run the ingestion command:
   ```bash
   python src/main.py ingest
   ```
4. Query your new policy immediately using `python src/main.py ask "..."`.

## Testing & Verification Guide

### Benchmark Question: Parental Leave
Run the following command:

```bash
python -m src.main ask "How many days of parental leave are allowed?"
# or: python src/main.py ask "How many days of parental leave are allowed?"
```

### Expected Result
The assistant retrieves `leave_policy.md > Parental and Family Leave` and outputs:
- **Primary Caregivers**: **26 weeks** of fully paid parental leave (100% of base salary).
- **Secondary Caregivers**: **6 weeks** of fully paid parental leave.
- Inline citation linking directly to `[1]` matching `leave_policy.md > Parental and Family Leave`.
- Similarity score: typically `>= 0.80` with cosine similarity.
